# 课件设计规范

**本文件管课件内核与内容写法，不管版式**：分节、标题、例子与代码块的位置由讲解角色按内容与学生偏好定，`MEMORY.md` 的个人偏好优先。页头、顶栏、主题开关、脚本由渲染器统一产出。题目、lab、实验说明页也不归本文件管。

## 一、着眼点（弱约束：按实际情况调整，不必强加内容）

1. **参考**：课件的结构与内容参考高中新课标权威教材（人教版、鲁科版、苏教版等）与近年高考真题命题导向；
2. **术语与符号规范**：
   - 物理/数学量必须使用规范标准符号（如位移 $x$、速度 $v$、加速度 $a$、质量 $m$、力 $F$）；
   - 数学物理公式一律使用标准 LaTeX 格式（行内公式用 `$公式$`，独立行居中公式用 `$$公式$$`）；
3. **深度与模型化**：
   - 讲透物理本质与推导过程，不搞死记硬背；
   - 重点提炼**经典模型**（如斜面滑块、传送带、碰撞、微元法、对称法）；
   - 给出**二级结论点睛**（用 `::: tip 二级结论` 标注，说明推导与适用边界）与**易错避坑速查**（用 `::: warn 考场陷阱` 标注）；
4. **练习与配图**：
   - 每节课必须配有直观的矢量图解（受力分析、过程示意、函数图像），使用 `svg-diagrammer` 生成标准 SVG，并放入 `::: svg` 块；
   - 随堂安排内嵌交互 Quiz 与典型母题巩固。

## 二、高中专属课型线索

| 课型 (`kind`) | 教学重心 | 核心元素 |
|---|---|---|
| **概念基石** | 物理概念由来、物理量定义与单位、内涵外延 | 生活情境 + 定义推导 + 适用条件 + 易错反例 |
| **经典模型** | 高考高频物理/几何模型的结构、过程与通法 | 状态与过程分析 + 规范受力/运动图解 + 二级结论 |
| **典型母题** | 高考真题母题精析、解题规范与变式拓展 | 审题破题点 + 规范分步列式 + 变式练习 |
| **实验探究** | 实验原理、仪器读数、数据处理与误差分析 | 装置示意图 + 实验原理推导 + 误差归因与创新延伸 |

## 三、复用与骨架（硬约束）

块名与用途见下表；语法以 `<root>/docs/课件内容格式.md` 为准：

| 要讲的东西 | 用哪个块 | 设计口径 |
|---|---|---|
| 一节 | `## 标题` | ≤14 字（进左侧目录），一节一个着眼点 |
| 公式定理 | `$$...$$` | 核心物理定理、能量/动量守恒方程，居中大公式 |
| 矢量图解 | `::: svg` | 受力分析、运动轨迹、电路、电磁场矢量图 |
| 二级结论 | `::: tip 二级结论：...` | 提炼高考解题快刀、金结论与适用条件 |
| 考场避坑 | `::: warn 易错警示：...` | 提示常见概念混淆、审题陷阱与边界遗漏 |
| 题目位置 | `::: quiz <层级> 锚点：<锚点文本>` | 留位，由 `practice-evaluator` 配高考母题与自测 |
| 延伸思考 | `::: note 拓展探究：...` | 高考压轴背景或大学物理先导微知识 |

**配图要绝对精准**：理科图绝不使用网络盗图，一律使用 `svg-diagrammer` 绘制规范的 `<svg>`。坐标系、力矢量、夹角、电荷极性必须与题干严格一致。

**一节的组织**：一个 `##` 一节，先场景与来历、再定义、再例子与代码、最后练习或题目位置收尾；

| 硬约束 | 怎么做 |
|---|---|
| 规范排版 | 采用 VitePress 标准 Markdown + KaTeX，支持原生内嵌 Vue 组件与 SVG |
| 文件命名 | `<序号>-<节点id>.md`（如 `0001-dynamics.force-analysis.md`），存放在 `<subject>/lessons/` |
| 矢量配图 | 使用 `::: svg [标题]` 或 `<SvgViewer>` 包装，由 VitePress 挂载全屏/放大与防塌陷交互 |
| 互动测试 | 选择题支持直接内嵌 `<QuizCard>`，高考大题支持 `<StepScoreCard>` 踩分自评 |
| 交付与同步 | 落盘后执行 `npm run sync`（`py -3 scripts/sync_to_vitepress.py`），即刻在 `http://localhost:5173/` 实时热更新 |

## 四、行文禁忌

1. **避免使用「肯定-否定」句式，如「不是...而是」**；不要先假定学生会往错的方向想
2. **避免使用生硬的修辞**，如「这个定义是从麻烦里长出来的」；简单的概念甚至不需要修辞
3. **避免代入用户视角行文**（如「编译落到你手上，就是一个具体动作」），不要"为了方便理解"反而加重用户负担
4. 非重点的章节或课程无须写得太详细。重点不明确会显著提高阅读负担
5. **不得将未学过的知识点放入当前课件**，常见情况为「引入用户不知道的库」「把用户没学过的东西放代码里面用」「大量的使用未学过的术语」，请把读者当作一个理解能力稍强的16岁学生，切记**读者不是全知全能的AI**
6. **不要过度口语化**，应当严格遵守下文的**教材式行文风格**
7. **交付前需重读交付物**，检查是否存在上述行文禁忌

## 五、行文风格（非常重要）

请以经典教材的教学性说明文体（didactic exposition）和教科书语体（textbook register）写作：以说明为主、辅以必要论证，保持学术语域与术语一致，概念首次出现时先定义，再用元话语和衔接把定义、例证、对比、小结等修辞关系自然串起来，借助脚手架式推进让读者从具体到抽象、由已知到未知地理解，语气克制、客观、清晰，少用口语、情绪和营销化表达，读起来像一本严谨、清晰、可自学的经典教材；例如可以这样落笔：「设函数 f 在区间 I 上有定义。若对任意 $x_1,x_2 \in I，当 x_1<x_2$ 时都有 $f(x_1) < f(x_2)$，则称 f 在 I 上严格递增。」「直观上，这意味着函数值随自变量增大而增大；但需要注意，单调性总是相对于某个区间而言的。」「本节先给出定义，再通过两个例子说明其用法，最后讨论常见误区。」
