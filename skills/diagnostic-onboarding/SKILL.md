# 高中学情动态诊断与大纲定制规范 (Diagnostic Onboarding)

传统网课的致命硬伤是“千人一面，必须从头听到底”。
本技能的作用是**打破一刀切，让每个高中生只学自己不会的，以最快速度提分**。

---

## 一、 动态诊断前测流程（3~5 道探针母题）

当学生开始新模块自学时，绝不立即倾倒全文，而是先进行**能力探针测试**：

1. **查阅学生画像**：
   - 读取 `workspace/.learning/profile.yaml` 中的 `grade`、`exam_region`、`target_score_band` 与 `learning_style`。
2. **生成梯级探针题（3 题极速定级法）**：
   - **探针 A（基石层·概念与受力）**：核心定理的前提与物理图像辨析（如：倾角增大时静摩擦力是否必增大？）；
   - **探针 B（核心层·常规母题）**：高考中档题型（如：带初速度滑块冲上斜面的加速度与分段运动）；
   - **探针 C（压轴层·综合临界）**：高考压轴临界或多过程题型（如：传送带共速临界、板块模型相对滑动临界）。
3. **证据核验与水平定级**：
   - **若 A/B/C 全对**：判定为「达到高考独立应用水平」，大纲与 progress 中该节点标记为 `status: 能独立应用, mastery: 1.0`，直接推荐跳过，进入下一高阶模块；
   - **若 A 对 B 对 C 错**：判定为「常规模型已过关，压轴综合存疑」，设为 `status: 初步理解, mastery: 0.65`（对应 L1+L2 达标），定制重点聚焦在临界状态拆解与压轴题型变式；
   - **若 A 对 B 错 / A 错**：判定为「基石概念与受力存在漏洞」，设为 `status: 学习中, mastery: 0.25`（仅达到 L1 浅层理解），定制路线必须包含前置概念支架与基础图解。

---

## 二、 动态重构 curriculum.yaml (自适应大纲裁剪)

根据前测结果，调度 `curriculum-designer` 执行以下操作：
1. **自动剪枝**：将学生已完全掌握的节点状态更新为 `能独立应用`，将其后续依赖节点的 `status` 激活为 `学习中`；
2. **靶向插入专项补给节点**：若学生在初中矢量合成、三角函数分解或某一核心概念存在严重断层，动态在大纲主线前插入形如 `dynamics.vector-math-remedial`（高数理基础补给）的小微节点；
3. **生成个性化学习契约（Learning Contract）**：
   向学生输出定制结果摘要：
   > “根据诊断，你对静摩擦力与常规正交分解掌握良好（跳过基础课）；你的核心卡点在于**滑块与接触面共速时的摩擦力突变**。已为你重新定制大纲：聚焦攻坚【传送带母题】与【板块临界模型】，预计节省 60% 无效听课时间！”

---

## 三、 同步落地

1. 更新 `workspace/.learning/subjects/<科目>/curriculum.yaml`；
2. 更新 `workspace/.learning/profile.yaml` 中的 `priorities` 与 `weakness_tags`；
3. 执行 `py -3 scripts/gen_home.py` 刷新路线图网页展示。
