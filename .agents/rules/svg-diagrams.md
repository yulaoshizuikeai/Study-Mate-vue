# 高中理科矢量图解规范 (SVG Diagrams Protocol)

本协议规定课件与答题解析中所有矢量 SVG 图解的绘制基准，确保在 Antigravity Artifacts、桌面端和移动端均具备一流观感。

## 一、 画布与视口标准
- 推荐 ViewBox：`0 0 780 370`（宽屏全景版）或 `0 0 600 320`（紧凑特写版）。
- 设置自适应样式：`style="max-width: 100%; height: auto; display: block; margin: 0 auto;"`。

## 二、 物理坐标系与局部变换
- 绝对禁止多元素全局绝对坐标硬堆叠。
- 必须使用 `<g transform="translate(x, y) rotate(deg)">` 实现局部元件解耦。
- 物块、滑轮、弹簧、小车应封装为相对原点 `(0,0)` 居中的独立图组。

## 三、 标准物理配色表
| 物理要素 | 标准色值 | 描述 |
| :--- | :--- | :--- |
| **受力矢量箭头** | `#ef4444` (红色) | $F, G, F_N, f, F_安, F_洛$ |
| **速度与位移** | `#38bdf8` (蓝色) | $v, v_0, x, s$，虚线辅助线 |
| **加速度** | `#22c55e` (绿色) | 标示系统或各分体加速度 $a$ |
| **电场线** | `#f59e0b` (橙黄) | 箭头指向低电势方向 |
| **磁感应强度** | `#a855f7` (紫色) | $\otimes$ (向里) / $\odot$ (向外) |
| **参考系/几何基底** | `#64748b` (中灰) | 斜面体、地面、滑轨、水平参考面 |

## 四、 课件嵌入契约
在课件 Markdown 内容文件中，使用渲染器原生的 `::: svg` 块指令：
```markdown
::: svg
<svg viewBox="0 0 600 320" xmlns="http://www.w3.org/2000/svg">
  ...
</svg>
:::
```
渲染器会自动为 SVG 套上 `.lesson-svg-container` 响应式外壳。
