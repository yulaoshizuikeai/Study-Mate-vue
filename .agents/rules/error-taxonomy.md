# 高中生认知错因归因体系 (Error Taxonomy)

在高中理科自学过程中，错题是提分的核心杠杆。每次自测后，智能体必须为错误分析归因，并记入该学科的 `misconceptions.yaml`。

## 一、 四大核心错因字典

### 1. [审题遗漏] (Omission of Key Conditions)
- **典型特征**：对题干隐蔽条件视而不见，或者误读情景。
- **高频场景**：
  - 漏看“光滑”、“轻质”、“不计空气阻力”、“带负电”；
  - 忽略“恰好不滑动”（静摩擦达到最大值）、“恰好过最高点”（弹力为零或临界速度）；
  - 混淆“位移大小”与“路程”、“速度变化量”与“速度变化率”。

### 2. [概念混淆] (Conceptual Misunderstanding)
- **典型特征**：在物理量定义或核心概念理解上存在根本偏差。
- **高频场景**：
  - 把向心力当成独立存在的“新力”；
  - 混淆滑动摩擦力与正压力的关系（误认为 $f$ 永远等于 $\mu mg$ 而不是 $\mu F_N$）；
  - 混淆平均速度 $\bar{v} = \frac{x}{t}$ 与匀变速中点时间速度 $\frac{v_0+v}{2}$ 的普适性。

### 3. [模型套错] (Model Misapplication)
- **典型特征**：死记公式，在不满足物理模型条件的情况下生搬硬套。
- **高频场景**：
  - 在变加速运动或非匀强电场中误用匀变速公式 $x = v_0t + \frac{1}{2}at^2$；
  - 在完全非弹性碰撞中误列机械能守恒；
  - 在带电粒子偏转中误将非对称磁场套用对称圆弧结论。

### 4. [计算失误] (Mathematical & Computational Errors)
- **典型特征**：物理方程列对，但数学运算、矢量方向或单位出现错误。
- **高频场景**：
  - 矢量正负号遗漏（如 $F - mg = ma$ 误写为 $F + mg = ma$）；
  - 单位未换算（如 $cm \to m$, $km/h \to m/s$）；
  - 三角函数诱导公式与几何勾股解方程错误。

## 二、 错题本记录标准格式 (misconceptions.yaml)
```yaml
- id: "err-dynamics-001"
  node: "newton.second-law"
  topic: "连接体受力与最大静摩擦临界"
  taxonomy: "审题遗漏"
  trigger_summary: "忽略题干'A与B恰好不发生相对滑动'的临界加速度条件"
  wrong_equation: "错误列出 f = \\mu m_A g，直接代入整体法"
  correct_thought: "隔离 A 物体求得临界加速度 a_max = \\mu g，再对整体列 F = (m_A + m_B)a_max"
  next_review_date: "2026-09-25"
  status: "待攻坚"
```
